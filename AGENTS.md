
# ClubFlow PA#2 - Project Rules

## Technology
- Use static HTML5 and CSS3.
- Do not use React or JavaScript.
- Do not install unnecessary dependencies.
- Use one shared stylesheet: styles.css.
- Do not depend on external CDNs.

## Required Pages
- index.html: Create Recruitment Campaign.
- review.html: Application Review.
- scheduling.html: Interview Scheduling.

## Responsive Design
- Support 360px, 768px and 1280px.
- Use mobile-first CSS.
- Prevent horizontal page overflow.
- Allow long text to wrap.
- Tables may scroll inside their own wrappers.
- Standalone buttons and links must be at least 44px tall.

## HTML
- Use semantic HTML5 elements.
- Use one h1 per page.
- Use proper heading hierarchy.
- Associate every input with a visible label.
- Use anchor elements for navigation.
- Use buttons for actions.
- Include viewport meta tags.

## Design
- Keep all three pages visually consistent.
- Body text must be at least 16px.
- Normal text contrast must be at least 4.5:1.
- Use a consistent spacing scale.
- Do not use custom !important declarations.

## Content
- Follow the ClubFlow project brief.
- Use consistent sample data across all pages.
- Do not use lorem ipsum.
- Do not confuse applicants with interviewers.
- Do not introduce the problems listed in Fix these.

## Quality Assurance
- All content must be visible with JavaScript disabled.
- All main navigation links must work.
- No broken relative links.
- Validate all pages with W3C Nu HTML Checker.
